FIELD MANUAL / 01

You’re on shift.

This is Northstar Logistics, a fictional company. You have ten investigations and a browser workbench. You don’t need another account or an installation.

  1. Read the assignment. Establish your authority and the evidence you need.
  2. Search the evidence. Use the built-in query language. Open records and attach those that support your decision. Two searches are required per case.
  3. Take bounded action. Write a reason and use the response console. Each action changes or checks the simulated environment.
  4. Write the case report. Explain observations, uncertainty, scope, response and next steps in your own words.
  5. Request review. Automatic checks assess completeness and known scenario outcomes, not the quality of your reasoning. Export your report for a human review.

What the lab does and does not do

Queries filter actual synthetic records; rule tests compute results against fixtures; file hashes are computed in your browser. Account, endpoint, quarantine, patch and callback actions change fictional state only. No live malware, real passwords, third-party messages or external network tests are involved.

All timestamps in evidence use UTC. Evidence is fixed; your audit actions use the current time. Progress stays in this browser. Export backups for portability. Source code contains the scenario outcomes; this is practice, not a secure examination.
